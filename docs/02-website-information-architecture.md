# Altovena – nettstedets informasjonsarkitektur v1.0

Status: plan, ikke ferdig design eller produksjonskode.

## Målgrupper

1. B2B-salgsorganisasjoner med behov for prospekt- og beslutningsintelligens.
2. Bedrifter og byråer som trenger SEO/AEO/GEO og bedre dokumentert synlighet.
3. Eiendomsvirksomheter som trenger en samlet kundereise.
4. Bedrifter med spesialisert drifts- eller automatiseringsbehov.

## Primær navigasjon

- **Products:** Offer Intelligence, Visibility, RealtyFlow, Olivia.
- **Solutions:** Sales Intelligence, AI Search Visibility, Real Estate, Operations.
- **Services:** Integration, Implementation, Managed Visibility.
- **Technology:** Nexus Intelligence, Architecture, Responsible AI, Security.
- **Insights:** Fagartikler, guider og oppdateringer.
- **Company:** About, Team, How We Work, Contact.
- **Primær CTA:** Book a Demo.

Unngå å vise mange tomme undermenyer ved lansering. Menyen kan være mindre enn fullstendig målarkitektur.

## Forsiden – prioritering

1. **Hero**: AI systems built for real work. Én undertekst som forklarer konkret verdi. CTA: Explore Products / Book a Demo.
2. **Business Outcomes**: Find opportunities; Grow visibility; Improve operations.
3. **Featured Products**: Offer Intelligence, Visibility, RealtyFlow; Olivia som eget verifisert case/pilot.
4. **How It Works**: Connect → Understand → Recommend → Approve → Act → Learn.
5. **Proof / Case Studies**: ekte produktbilder og dokumentert kunde-/pilotarbeid. Aldri oppdiktede KPIer eller logoer.
6. **Human Control**: data, tilgangsmodeller, godkjenninger og ansvar.
7. **Team / About**: de fire navngitte rollene med godkjent presentasjon.
8. **CTA**: en konkret demoforespørsel.

## Produktside-mal

- Ett H1-løfte og et kort direkte svar på hva produktet løser.
- For hvem og hvilket forretningsproblem.
- Tre til fem dokumenterbare funksjoner.
- En reell demo eller tydelig eksempel merket som illustrasjon.
- Prosess og integrasjoner.
- Sikkerhet, menneskelig kontroll og ansvar.
- Transparent status: available / private pilot / planned, basert på verifisert status.
- FAQ for ekte spørsmål, relevante lenker og CTA.
- Navngitt eier/ansvarlig dersom avtalt.

## Designretning

Premium, rolig og tydelig. Lys bakgrunn, dype blåtoner og en diskret aksent, høy kontrast, produktnære illustrasjoner og ekte skjermbilder. Ingen neon-klisjeer, generiske roboter eller fiktive dashbord som fremstilles som reelle.

Prinsipper: mobile first; WCAG-orientert lesbarhet; tydelige interaktive tilstander; gode tabeller også på mobil; dokumentert ytelse og Core Web Vitals.

## SEO/AEO/GEO

- Én tydelig hovedintensjon per URL, hub/cluster-struktur og direkte svar.
- Synlig forfatter og reell oppdateringsdato for fag- og regelfølsomt innhold.
- Unike metadata, canonical, sitemap, riktig hreflang og strukturert data som matcher siden.
- Servergjengitt tilgjengelig innhold og vanlige lenker.
- Internlenker i relevant brødtekst, ikke repetitive lenkesamlinger.
- Unngå søkeordkannibalisering mellom Altovena, ChatGenius og personlige nettsteder.
- Mål impresjoner, klikk, AI-referanser der mulig, demoforespørsler og faktisk salg.

## Før publisering

Bekreft ekte produktstatus, rettigheter til skjermbilder, person-/virksomhetspresentasjoner, juridiske sider, cookie/personvern, sikkerhetspåstander og kontaktinformasjon.
