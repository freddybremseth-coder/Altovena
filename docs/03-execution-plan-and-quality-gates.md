# Altovena – gjennomføringsplan og kvalitetsporter

Plan v1.0 – 13. oktober 2026. Milestone-basert, ikke en påstand om påbegynt eller fullført utvikling.

## Fase 0 – beslutningsgrunnlag

- Godkjenn Altovena som offentlig merkevare, juridisk navn separat.
- Registrer domene og avklar varemerke, jurisdiksjon, personvern og kontrakter.
- Bekreft personroller og offentlige biografier, med godkjenning fra personene.
- Kartlegg reell funksjons-/demo-/lanseringsstatus per produkt.
- Sett budsjettgrenser og ansvar for Anna.

**Port:** ingen kommersiell «available»-påstand uten godkjenning.

## Fase 1 – design og første nettsted

- Velg teknologistack, hosting og driftsansvar etter ytelse, vedlikehold og tilgangsbehov.
- Bygg grunnleggende design tokens, komponentbibliotek, navigasjon, footer og responsive sider.
- Lag de første sidene: forside, produkter, produktdetaljer, teknologi, om oss, demo.
- Skriv engelsk og norsk manuelt kvalitetssikret innhold.
- Legg inn verifiserte navn: Freddy Bremseth, Anna Bremseth, Andrea Thorsnes Karlsen og Erlend Thorsnes Karlsen.
- Før inn faktiske produktbilder der rettigheter og representativitet er kontrollert.

**Port:** språk, design og innhold godkjent av Andrea; SEO-struktur av Erlend; produktpåstander av Freddy.

## Fase 2 – måling og salgsflyt

- Demoforespørsel → mottak → samtykke → lead i riktig system → menneskelig oppfølging.
- GA4/Search Console og hensiktsmessige personvern-/samtykkeinnstillinger.
- Mål per produkt: trafikk, organisk/AI-synlighet, demoer, kvalifiserte leads, kunder.
- Vurder «book a demo» før selvbetjente betalinger for produkter som krever konfigurering.

**Port:** ingen falske handlinger i UI, fungerende lenker og testet leadflyt.

## Fase 3 – kommersielle piloter

- Offer Intelligence: avgrenset tilbud; separate data-quality og interest-indication signaler; menneskelig godkjenning.
- Visibility: metodikk eiet av Erlend; audit → anbefaling → utkast → godkjenning → måling.
- RealtyFlow: rolle som ekte vertikal referanse; produktstatus verifiseres før salgspåstander.
- Olivia: merket som pilot/case inntil salgsberedskap er vurdert.

**Port:** kost og kapasitet gjennomgås av Anna; teknisk leveransedyktighet av Freddy; faglige påstander av relevant eier.

## Fase 4 – lansering og videreføring

- QA på mobil/desktop: kontrast, tabeller, navigasjon, skjema, lenker og 404.
- Teknisk QA: build, typecheck, avhengigheter, sårbarheter, sitemap/canonical/hreflang, robots, SEO og riktig indeksering.
- Kontroller cookie/personvern, vilkår, selskapsopplysninger og sporbarhet for leads.
- Lansering separat fra ChatGenius; ingen tvungen omdirigering av hele ChatGenius-nettstedet.
- Mål effekt før innholdsproduksjon utvides.

## Mål for første 90 dager etter beslutning

1. Én konsistent Altovena-brand og fungerende lanseringsnettsted.
2. Minst én reell produktdemo og én verifisert case (uten oppdiktede data).
3. Definert salgstilbud for en avgrenset B2B-pilot.
4. Samlet, personvernforsvarlig demo- og leadrapportering.
5. Første måling av organisk synlighet og faktiske kommersielle henvendelser.
6. Dokumentert kostnads- og kvalitetskontroll.

Ingen bestemt salgs- eller trafikkvekst garanteres. Ressursplan og frister fastsettes etter at den tekniske førsteversjonen er estimert.
